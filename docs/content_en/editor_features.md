# UVE_EDITOR: Complete feature surface

UVE_EDITOR exposes the UVE environment through an editor-centered workspace:

- project overview and path configuration;
- sub-project summaries and configuration files;
- design folders, schematics, registers, and design analysis;
- filelists, documentation, precompile settings, and generated artifacts;
- toolchain status and environment inspection;
- test status and spreadsheet analysis;
- regression status, dashboards, reports, logs, and rerun information;
- simulation summaries;
- package classes, sequences, interfaces, defines, parameters, and consistency;
- flow defines, UVM information, testlists, register templates, and coverage templates;
- source-file navigation and refreshable project analysis; and
- the complete integrated User Guide.

The extension supports local and remote workspaces and provides a unified navigation surface for project, design, verification, analysis, and automation views.
