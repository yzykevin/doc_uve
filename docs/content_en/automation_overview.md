# UVE_AUTOMATION: Complete automation capabilities

UVE_AUTOMATION covers the generation and maintenance tasks that turn project descriptions into repeatable verification assets.

## Generated verification assets

- register models and register-related components;
- SystemVerilog RTL and software-facing register artifacts;
- UVM agent, environment, register, and sequence templates;
- DUT and HVL top-level scaffolding;
- testbench include files and filelists;
- test and testlist templates;
- base tests and reusable test infrastructure;
- functional-coverage templates;
- Jasper-oriented project templates and check artifacts;
- report and statistical-analysis artifacts; and
- configuration templates and format-conversion outputs.

## Automatic project composition

UVE_AUTOMATION supports automatic design filelist generation, DUT filelist generation, testbench filelist generation, test include generation, configurable wrappers, and composition of reusable verification sub-environments. A project can add or replace sub-environments for different IP, subsystem, and SoC verification contexts.

## Self-check and result automation

Automation is connected to project self-checks, testlist validation, precompile consistency checks, pytest-based test collection, simulation and regression result analysis, report generation, and workspace cleanup.
