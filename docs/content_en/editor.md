# UVE_EDITOR: VS Code project exploration and review extension

UVE_EDITOR integrates the UVE environment into VS Code and provides a project-aware navigation and review workspace.

## Project and environment views

- project overview and project-path configuration;
- toolchain and environment inspection;
- tool versions and detected tool status;
- sub-project summaries and configuration views;
- design folders, schematics, registers, and design analysis;
- filelists, documentation files, precompile configuration, and generated artifacts; and
- project refresh and configuration editing.

## Verification views

- test status and test spreadsheet analysis;
- regression status, dashboards, reports, logs, and rerun information;
- simulation summaries;
- UVM classes, sequences, interfaces, defines, and parameters;
- package and cross-package consistency analysis;
- flow defines, UVM information, testlists, register-generation templates, and coverage templates; and
- the complete integrated UVE User Guide.

## Development experience

The extension supports local and remote development sessions, automatic project-root discovery, workspace project-path overrides, refreshable analysis, source-file navigation, and theme-aware views.
